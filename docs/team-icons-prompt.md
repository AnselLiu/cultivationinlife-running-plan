# 分團小圖：ChatGPT 生圖指令

用途：網站裡區分各分團的小圖示，用在分團頁、首頁篩選、活動卡片。顯示尺寸很小（約 28–64 px），所以要**一眼看得出是哪一團**，不靠細節。

## 先做這件事

在 ChatGPT 新對話**先上傳原本的耕跑團 logo**（`public/icons/icon-512.png`，藍底黃色毛筆「耕」字＋RUN），再貼下面的指令。有參考圖，生出來的筆觸和配色才會像同一家人。

## 共同規格（每一張都一樣）

- 尺寸：1024 × 1024，正方形，PNG
- 背景：**滿版單一底色**（網站會裁成圓形或圓角方形，四角不要放東西）
- 主體置中，四周留約 12% 邊界，縮到 48 px 還看得清楚
- 風格：跟原 logo 同一套，黃色（#FDF36D）毛筆書法筆觸，粗、有飛白，平面、不要立體、不要陰影、不要漸層
- 不要放小字、不要外框、不要浮水印

## 共同開頭（每張指令都先貼這段）

```
參考我上傳的「耕跑團」logo：藍底、黃色毛筆書法的「耕」字，下面有毛筆寫的 RUN。
請用同一套視覺語言，幫我做一個「分團」的小圖示：
- 1024×1024 正方形 PNG，滿版單色背景，主體置中，四周留 12% 邊界
- 黃色 #FDF36D 毛筆書法筆觸，粗獷、有飛白，平面設計，不要立體、陰影、漸層、外框、小字
- 縮小到 48 像素時還要一眼認得出來
```

## 生不好的時候可以補一句

- 字寫錯或變成亂碼：「中文字一定要寫對，只寫一個字：『青』，不要其他中文。」
- 太複雜：「再簡化，只留一個字和英文，拿掉所有裝飾。」
- 顏色跑掉：「背景一定是純色 #2E9D6A，筆刷一定是純色 #FDF36D。」
- 有陰影或立體感：「完全平面，像印章一樣，不要任何陰影與光影。」

## 做好之後

1. 存成 PNG。
2. 到網站：我的 → 全部分團 → 點分團 → 「分團資料」→ 「分團圖示」選檔上傳（理事長、行政人員或該團團長都可以換）。網站會自動縮成小圖存起來，不用自己裁。
