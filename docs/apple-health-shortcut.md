# Apple 健康捷徑製作說明

讓團員在 iPhone 上按一下（或對 Siri 說一句話），就把最新一筆跑步的距離、時間帶進耕跑團。不用訂閱任何服務，資料只在 iPhone 與網頁之間傳遞，不經過協會伺服器以外的地方。

做一次就好：由一位幹部在自己的 iPhone 做好、分享成 iCloud 連結，貼到「系統設定 → 倒數與捷徑」，其他人從「拍照分享 → Apple 健康」一鍵加入。

> 捷徑 App 的動作名稱會隨 iOS 版本略有不同，找不到時用搜尋框打關鍵字（例如「體能訓練」「格式化」「URL」）。

## 步驟

1. 打開「捷徑」App → 右上角「＋」新增捷徑，命名為 **耕跑團記錄**（Siri 會用這個名字）。
2. 加入動作 **尋找體能訓練**（或「尋找健康樣本」→ 類型選體能訓練）：
   - 篩選：類型 **是** 跑步
   - 排序：開始日期，**最新的在前**
   - 限制：**1** 筆
3. 加入 **取得體能訓練的詳細資訊** 三次，分別取：
   - **距離**（單位選公里）
   - **時間長度**（單位選分鐘）
   - **開始日期**
4. 加入 **格式化日期**：輸入選上一步的「開始日期」，格式選「自訂」，填 `yyyy-MM-dd`。
5. 加入 **文字**，內容如下（中括號的地方從變數列點選，不要自己打）：

   ```
   https://cil-run.anselliu7.workers.dev/#/log?km=[距離]&min=[時間長度]&date=[格式化的日期]&src=health
   ```

   - 想先拍照分享再記錄：把 `#/log` 改成 `#/studio`
6. 加入 **打開 URL**，輸入選上一步的「文字」。
7. 執行一次：第一次會詢問能否讀取「健康」資料，選允許。
8. 右上角分享 → **拷貝 iCloud 連結**，貼到網站「系統設定 → 倒數與捷徑 → Apple 健康捷徑」儲存。

## 網址參數

| 參數 | 意思 | 例子 |
|---|---|---|
| `km` | 距離（公里，可以有小數） | `10.25` |
| `min` 或 `sec` | 時間（分鐘或秒，擇一） | `min=55.5` 或 `sec=3330` |
| `date` | 日期 `YYYY-MM-DD`，沒帶就是今天 | `2026-10-02` |
| `hr` | 平均心率（選填） | `152` |
| `src` | 固定填 `health` | `health` |

網站收到後會自動對上那天的課表，團員確認、補上自覺強度與感覺後按儲存即可。
